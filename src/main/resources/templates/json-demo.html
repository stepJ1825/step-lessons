📚 Синтаксис JSON на примере книги

JSON (JavaScript Object Notation) — лёгкий формат обмена данными. Он легко читается людьми и машинами.

Пример JSON-объекта «Книга»

{
  "id": 1,
  "title": "1984",
  "author": "Джордж Оруэлл",
  "genre": "Антиутопия",
  "year": 1949,
  "available": true,
  "tags": [
    "Классика",
    "Политика",
    "Философия"
  ]
}

💡 Пояснение синтаксиса JSON:

  • Данные представлены в виде пар «ключ: значение».
  • Ключи всегда — строки в двойных кавычках.
  • Значения могут быть: строка, число, логическое (`true`/`false`), `null`, массив (`[]`) или объект (`{}`).
  • Элементы разделяются запятыми, но запятая не ставится после последнего элемента.
  • Весь объект заключён в фигурные скобки `{}`.
  • Массив — в квадратные скобки `[]`.
  • Комментарии в JSON запрещены!

Сравнение: Java vs JSON

Java (Book.class) JSON
private Long id; "id": 1
private String title; "title": "1984"
private List<String> tags; "tags": ["Классика", "Политика"]
private boolean available; "available": true

Как получить этот JSON?

Откройте в браузере или через curl:

GET http://localhost:8080/books/example

Этот эндпоинт возвращает реальный JSON, сгенерированный Spring Boot с помощью Jackson.
