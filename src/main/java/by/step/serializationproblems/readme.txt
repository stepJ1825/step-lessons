Чтобы продемонстрировать ошибку несовместимости версий сериализуемого класса при десериализации в Java, нужно:
1.Создать сериализуемый класс с serialVersionUID.
2.Сохранить объект этого класса в файл.
3.Изменить структуру класса (например, добавить/удалить поле) без изменения serialVersionUID.
4.Попытаться прочитать старый объект — будет выброшено исключение InvalidClassException.

⚠️ Если вы не указываете serialVersionUID явно, Java генерирует его автоматически на основе структуры класса.
Любое изменение в классе (даже добавление поля) приведёт к изменению этого ID и ошибке при десериализации.

Ошибка java.io.InvalidClassException возникнет при:
- Изменён serialVersionUID (явно или неявно).
- Изменён тип существующего поля (например, int age → String age).
- Класс перестал реализовывать Serializable.
