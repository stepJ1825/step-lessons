public enum ElementType {

* TYPE, // Класс, интерфейс, enum, аннотация
* FIELD, // Поле класса
* METHOD, // Метод
* PARAMETER, // Параметр метода
* CONSTRUCTOR, // Конструктор
* LOCAL_VARIABLE, // Локальная переменная
* ANNOTATION_TYPE,// Другая аннотация
* PACKAGE, // Пакет
* TYPE_PARAMETER, // Параметр типа (Generics)
* TYPE_USE // Любое использование типа
  }

-------------------------------
public enum RetentionPolicy {

* SOURCE, // Аннотация сохраняется только в исходном коде
* CLASS, // Аннотация сохраняется в байт-коде, но недоступна во время выполнения
* RUNTIME // Аннотация сохраняется в байт-коде и доступна во время выполнения через Reflection
  }

-------------------------------
Сочетания Retention и Target:

| Use Case                   | Retention | Target              |
|----------------------------|-----------|---------------------|
| Аннотация для компилятора  | SOURCE    | METHOD, FIELD       |
| Аннотация для фреймворк 	  | RUNTIME   | TYPE, METHOD        |
| Аннотация для анализа кода | SOURCE    | TYPE, METHOD, FIELD |
| Аннотация для сериализации | RUNTIME   | FIELD               |

-------------------------------

#### Правила комбинирования:

1. Если не указать @Retention - по умолчанию используется RetentionPolicy.CLASS
2. Если не указать @Target - аннотацию можно применять к любому элементу
3. Можно указывать несколько Target - использовать массив {TYPE, METHOD, FIELD}

-------------------------------

#### Ошибки компиляции:

// ❌ НЕ СКОМПИЛИРУЕТСЯ - аннотация @Service не может применяться к полю
`@Service
private String serviceName;`

// ❌ НЕ СКОМПИЛИРУЕТСЯ - аннотация @Inject не может применяться к классу
`@Inject
public class MyService { }`
------------------------------

#### Заключение

* `@Retention(RetentionPolicy.RUNTIME)` - делает аннотацию доступной через Reflection API
* `@Target({ElementType.TYPE, ElementType.METHOD, ElementType.FIELD})` - позволяет применять аннотацию к классам,
  методам и полям

Это сочетание обычно используется для аннотаций, которые должны обрабатываться фреймворками во время выполнения
программы (Spring, Hibernate, кастомные фреймворки).
