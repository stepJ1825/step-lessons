## ✅ Синтаксис JSON?

| Возможность JSON               | Пример из кода                                        | Пояснение                                                               |
|--------------------------------|-------------------------------------------------------|-------------------------------------------------------------------------|
| **Число (целое)**              | `"id": 42`                                            | Целые числа записываются без кавычек                                    |
| **Число (с плавающей точкой)** | `"rating": 4.9`                                       | Поддержка десятичных дробей                                             |
| **Строка**                     | `"title": "Мастер и Маргарита"`                       | Обязательно в **двойных кавычках**                                      |
| **Логическое значение**        | `"available": true`                                   | Только `true` или `false` (без кавычек)                                 |
| **Значение `null`**            | `"isbn": null`                                        | Обозначает отсутствие значения                                          |
| **Массив**                     | `"tags": ["классика", "фэнтези", "сатира"]`           | Упорядоченный список в квадратных скобках `[ ]`                         |
| **Объект**                     | `"publisher": { "name": "АСТ", "country": "Россия" }` | Неупорядоченная коллекция пар «ключ: значение» в фигурных скобках `{ }` |
| **Вложенные объекты**          | `"publisher"` внутри основного объекта                | Объект может содержать другие объекты                                   |
| **Массив объектов**            | `"translations": [ { ... }, { ... } ]`                | Часто используется для представления списков сущностей                  |
| **Пустой массив**              | `"reviews": []`                                       | Допустимо и часто применяется при отсутствии данных                     |
| **Числа в массиве**            | `"dimensions": [14.5, 21.0, 2.8]`                     | Массив может содержать числа, строки, и даже другие объекты             |

## ⚠️ Что **нельзя** в JSON (распространённые ошибки)

| Неправильно ❌                | Правильно ✅                 | Почему                                                           |
|------------------------------|-----------------------------|------------------------------------------------------------------|
| `'title': 'Книга'`           | `"title": "Книга"`          | Ключи и строки **только в двойных кавычках**                     |
| `{ title: "Книга" }`         | `{ "title": "Книга" }`      | Все ключи **обязательно** в кавычках                             |
| `// это комментарий`         | —                           | **Комментарии запрещены** в JSON                                 |
| `"status": undefined`        | `"status": null`            | `undefined` не существует в JSON                                 |
| `{ "a": 1, }`                | `{ "a": 1 }`                | Запятая после последнего элемента **недопустима**                |
| `{ "date": new Date() }`     | `{ "date": "2025-12-08" }`  | Функции и объекты вроде `Date` не поддерживаются — только данные |
| `{ "tags": [ "фэнтези", ] }` | `{ "tags": [ "фэнтези" ] }` | Запятая в конце массива — ошибка                                 |
| `"name": Иван`               | `"name": "Иван"`            | Строки без кавычек — синтаксическая ошибка                       |
