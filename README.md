## 📄 Поддерживаемые HTML-теги в проекте

В проекте продемонстрировано использование основных HTML-тегов, сгруппированных по категориям:

| Категория       | Теги                                                                                                        |
|-----------------|-------------------------------------------------------------------------------------------------------------|
| **Структура**   | `html`, `head`, `body`, `header`, `nav`, `main`, `section`, `footer`                                        |
| **Текст**       | `p`, `h1`–`h6`, `strong`, `em`, `u`, `del`, `mark`, `code`, `var`, `samp`, `kbd`, `abbr`, `q`, `blockquote` |
| **Списки**      | `ul`, `ol`, `li`, `dl`, `dt`, `dd`                                                                          |
| **Таблицы**     | `table`, `caption`, `thead`, `tbody`, `tr`, `th`, `td`                                                      |
| **Формы**       | `form`, `input`, `textarea`, `button`, `label`, `fieldset`, `select`, `option`                              |
| **Медиа**       | `img`, `figure`, `figcaption`, `audio`, `video`, `source`                                                   |
| **Интерактив**  | `details`, `summary`, `progress`, `ins`                                                                     |
| **Мета/прочее** | `meta`, `title`, `style`, `link`, `DOCTYPE`                                                                 |
