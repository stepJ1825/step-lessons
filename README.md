### Практическое задание: Система управления библиотекой
#### Цель задания
Разработать систему управления библиотекой с использованием основных концепций Java: ООП, функциональное программирование, Stream API, коллекции и строки.
#### Задача
Создать программу для управления книгами в библиотеке. Система должна предоставлять функциональность для добавления, поиска, фильтрации и статистики по книгам.

#### Требования к реализации
1. ООП (Классы и интерфейсы)
- Создать следующие классы:
  - Book (книга с полями: id, title, author, genre, year, rating)
  - Library (библиотека, управляющая коллекцией книг)
  - BookFilter (функциональный интерфейс для фильтрации книг)
2. Функциональное программирование
- Использовать лямбда-выражения и функциональные интерфейсы для:
  - Фильтрации книг
  - Сортировки
  - Обработки коллекций
3. Stream API
- Применить Stream API для:
   - Поиска книг
   - Статистических вычислений
   - Группировки данных
   - Преобразования коллекций
4. Java Collection Framework
- Использовать различные коллекции:
   - List для хранения книг
   - Map для группировки по категориям
   - Set для уникальных авторов/жанров
5. Строки
- Работа со строками:
   - Форматирование вывода
   - Поиск по подстроке
   - Преобразование регистра
   - Конкатенация и StringBuilder

### Конкретные задания
#### Часть 1: Базовые классы и интерфейсы
- Создать класс Book
- Создать функциональный интерфейс BookFilter
- Создать класс Library с коллекцией книг
#### Часть 2: Реализация функциональности
- 2.1 Добавьте методы в класс Library:
   - addBook(Book book) - добавить книгу
   - removeBook(int id) - удалить книгу по ID
   - findBooksByAuthor(String author) - найти книги автора
   - findBooksByYearRange(int start, int end) - найти книги по диапазону годов
- 2.2 Реализуйте методы с использованием Stream API:
   - getAllBooks() - вернуть все книги
   - getBooksByFilter(BookFilter filter) - фильтрация книг
   - getAverageRating() - средний рейтинг всех книг
   - getBooksGroupedByGenre() - книги сгруппированные по жанру
#### Часть 3: Расширенная функциональность
- 3.1 Создайте методы для работы со строками:
   - searchBooks(String keyword) - поиск по названию и автору (игнорируя регистр)
   - getBookTitlesAsString() - все названия книг в виде строки через запятую
   - getAuthorStatistics() - статистика по авторам (количество книг каждого автора)
- 3.2 Реализуйте сортировку:
   - getBooksSortedByTitle()
   - getBooksSortedByRatingDesc()
   - getBooksSortedByYear()
#### Часть 4: Дополнительные задания
- 4.1 Создайте метод для поиска книг с использованием предикатов:
`List<Book> findBooks(Predicate<Book> predicate)`
- 4.2 Реализуйте метод для получения топ-N книг по рейтингу
- 4.3 Создайте метод для проверки дубликатов книг (по названию и автору)
- 4.4 Реализуйте экспорт данных в форматированной строке
