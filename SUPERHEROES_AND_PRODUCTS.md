Задачи
1. Выведите имена и год первого появления всех супергероев из вселенной 'marvel', у которых цвет глаз 'Blue Eyes'.
2. Найдите общую сумму (SUM) цен всех продуктов, тип которых 'Онлайн-курс' (type_name в product_types).
3. Используя JOIN, выведите название продукта, тип продукта (из таблицы product_types) и его цену для всех продуктов, цена которых больше 20000.
4. Для каждого типа продукта (type_name) посчитайте количество продуктов, относящихся к этому типу. Выведите название типа и количество.
5. Найдите имя клиента и дату заказа для всех заказов, сделанных клиентом по имени 'Иван Петров'.
6. Выведите имена супергероев, у которых количество появлений (appearances) больше 50 и которые являются 'Good Characters'.
7. Найдите продукт с самой высокой ценой. Выведите его название и цену. (Подсказка: используйте ORDER BY и LIMIT).
8. Используя подзапрос, найдите всех клиентов (customers), у которых нет ни одного заказа (orders).
9. Посчитайте общее количество заказов (orders) для каждого клиента. Выведите имя клиента и количество заказов. Включите в результат даже тех клиентов, у которых заказов не было (в этом случае количество должно быть 0). (Подсказка: используйте LEFT JOIN и COALESCE или ISNULL).
10. Найдите среднее количество появлений (AVG(appearances)) супергероев по полу (gender) в каждой вселенной (universe). Выведите вселенную, пол и среднее количество появлений.
